# Transformer

整个大模型训练过程分为：前向传播，计算损失，反向传播，梯度下降。

前向传播：输入长度为 n 的 Token 序列，经过多层 Transformer 。

每一层 Transformer 的计算为：
- 输入序列构成一个矩阵 X ([n, d_model] d_model 是每个 Token 的向量长度)
- 矩阵 X 与模型参数矩阵 W_Q, W_K, W_V ([d_model, d_k]) 相乘得到 Query, Key, Value ([n, d_k] d_k 是注意力头维度)
- 矩阵 Q 和 K 的转置矩阵相乘再除以 √d_k 得到注意力分数矩阵 [n, n]
- 对每行做 softmax 归一化，得到注意力权重矩阵（每行和为1）
- 单头输出：注意力权重矩阵与 V 矩阵相乘得到注意力输出矩阵 [n, d_k]
- 多头注意力：并行计算 h 个头的不同输出（如上单头输出），拼接后乘以输出投影矩阵 W_O 得到融合多视角的注意力结果 [n, d_model]
- 残差连接 & 层归一化 `X1 = LayerNorm(X + 多头注意力结果)` 目的是保留原始信息并防止数值梯度爆炸或梯度消失
  - 层归一化先强制让每一行的输入均值固定为 0 ，方差固定为 1 ，再有可学习的 γ β 做线性变化微调值
- 前馈网络 `X2 = FFN(X1)` 将 X1 矩阵升至高维后进行非线性变换再降回原维度，普遍认为存储的知识都编码在前馈网络权重里
- 再次残差连接 & 层归一化 `输出 = LayerNorm(X1 + X2)` 传入下一层

最后一层 Transformer 输出的 H [n, d_model] 矩阵，再乘以 W_lm ([d_model, V] V 是模型能够识别的所有 Token 的总数) 得到 logits [n, V]
- 其中第 i 行代表着给定前 i 个 Token，预测第 i+1 个 Token 的概率分布
- 训练时因此可以同时训练所有 Token 的预测能力（通过 因果掩码 保证模型只能看到之前的 Token ）
- 生成时使用新生成的 Token 构成新矩阵 [n+1, d_model] 重复上面过程（同样因为 因果掩码 所以前 n 行的概率不会改变）
  - 为防止重复计算，因此存在 KV Cache 设计来直接获取部分结果

计算损失：交叉熵损失
- 概率矩阵 S [n, V] 对于每个 i in n ，都有一个概率分布 P_i ，计算 `Loss_i = -log( P_i[y_i] )` 其中 y_i 是正确答案，概率越接近 1 ，损失越小
- 损失值 `L = (1/n) * Σ Loss_i` 即为平均值，是个标量

反向传播：从损失函数 L 出发，从后往前逐层应用链式法则计算，算出每个可学习参数的梯度
- 所有层的 W_Q W_K W_V W_O ，前馈网络的 W1 W2 ，曾归一化的 γ β ，和最后的 W_lm

梯度下降：用优化器根据梯度更新模型参数
